# Add these 4 images before deploying

The site now expects real photos instead of the placeholder illustration.
Grab these from Unsplash or Pexels (both free, no attribution required) —
takes about 2 minutes:

| File to save here | What to search for | Suggested size |
|---|---|---|
| `hero-house.jpg` | "modern house exterior dusk" or "hill country modern home" | landscape, 1600px+ wide |
| `listing-1.jpg` | "modern house exterior" | landscape, 800px+ wide |
| `listing-2.jpg` | "modern farmhouse exterior" | landscape, 800px+ wide |
| `listing-3.jpg` | "lake house exterior" | landscape, 800px+ wide |

Steps:
1. Go to unsplash.com, search each term above
2. Download the "Small" or "Regular" size (no need for full-res)
3. Rename to match the filenames in the table exactly
4. Drop all 4 into this `public/images/` folder, replacing this file

If a file is missing, that image slot will just show a broken image icon —
it won't break the build or the rest of the site, but do this before
recording the demo video.

(Delete this README-IMAGES.md file itself once the real images are in place — it's just instructions, not used by the app.)
